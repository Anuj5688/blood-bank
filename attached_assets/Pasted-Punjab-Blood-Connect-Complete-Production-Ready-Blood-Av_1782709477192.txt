Punjab Blood Connect – Complete Production-Ready Blood Availability Platform

Build a production-ready Android and Web application called Punjab Blood Connect that provides real-time blood availability across hospitals and blood banks in Punjab, India.

This application must use real database integration (no dummy data) and include complete authentication, hospital registration, approval workflow, inventory management, admin controls, analytics, and secure APIs.

---

Objective

Create a centralized platform where users can instantly search blood availability by city, hospital, blood bank, or blood group.

Only approved hospitals and blood banks should be visible to the public.

---

User Roles

- Super Admin
- Hospital/Blood Bank
- Public User

---

Users can:

- Search by City
- Search by District
- Search by Blood Group
- Search Hospitals
- Search Blood Banks
- View Available Blood Units
- View Blood Stock Status
- View Last Updated Time
- View Hospital/Blood Bank Name
- View Address
- View Contact Number
- Open Google Maps
- Call Hospital/Blood Bank directly

Only approved hospitals and blood banks should appear in search results.

---

Punjab Coverage

Include all districts and major cities of Punjab.

The database should support unlimited cities and future expansion to all Indian states.

Complete Hospital & Blood Bank Registration System

Hospitals and Blood Banks can register themselves.

Create a registration form containing:

- Hospital/Blood Bank Name
- Registration Number
- Hospital Type
- Government / Private
- City
- District
- State (Punjab)
- Complete Address
- PIN Code
- Google Maps Location
- Contact Person
- Mobile Number
- Email
- Password
- License Upload (PDF/JPG)
- Hospital Logo (Optional)

After submission:

- Save all information in PostgreSQL.
- Registration Status = Pending Approval.
- Do not show the hospital publicly until approved.
